# 真机验证清单

模拟器无法覆盖的项，按顺序执行。

## 0. 安装前

- [ ] 停闭环、导出配置、记录当前版本与配置文件名
- [ ] 核对 APK 的 SHA-256 与证书指纹（见 VERIFICATION.md）
- [ ] 确认设备已备份上一版 APK，便于回滚（注意降级会触发数据库迁移风险）

## 1. 首次启动

- [ ] 电池优化豁免
- [ ] AAPS 目录 SAF 授权
- [ ] 通知权限（8.1 为安装时授予）
- [ ] 蓝牙权限（8.1 为运行时权限）
- [ ] 厂商 ROM 的自启动 / 后台白名单

## 2. 传感器开关（10 分钟）

- [ ] 拿设备走 100 步，步数增量接近 100
- [ ] 放桌上 10 分钟，步数增量接近 0
- [ ] 如开启心率源：静坐 2 分钟，HR 数值合理且不跳变

任一项不通过：关闭对应开关，Boost 退回纯血糖驱动。

## 3. 硬件链路

- [ ] 蓝牙泵配对、基础率下发、断开重连
- [ ] CGM 数据接入与断连恢复
- [ ] 报警：低血糖、无数据、泵异常

## 4. 保活与 Doze

- [ ] 锁屏 1 小时后循环是否准时
- [ ] 深 Doze 后临时基础率是否延迟补算
- [ ] 重启设备后自动恢复（BOOT_COMPLETED、前台服务）
- [ ] 进程被杀后能否自动拉起

## 5. 渐进使用

- [ ] 开环 24 小时
- [ ] 闭环小剂量 24 小时
- [ ] 连续 72 小时：0 崩溃、0 ANR、内存增长 <10%

## 6. 耗电（开启心率源时）

- [ ] 关闭心率源 1 小时，`dumpsys batterystats` 记录 AAPS UID 耗电
- [ ] 开启心率源 1 小时，同样记录
- [ ] 若偏高，把采样间隔调到 10–15 分钟再测
