## 7. 长稳测试（6-12h）

| 项目 | 内容 |
|------|------|
| **目的** | 长时间运行无内存泄漏、无 Service 崩溃、日志系统稳定 |
| **前置** | 完整 setup wizard 完成，连接模拟泵 + CGM |
| **步骤** | 1. 启动应用并保持前台 6-12h（自动循环：启动服务 → 发送假数据 → 观察日志）<br>2. 每 2 小时检查 `adb shell dumpsys meminfo info.androidaps.aaps \| grep -E "TOTAL PSS|Activities|Services"` |
| **预期** | - PSS 内存稳定（波动 < 20%）<br>- Services 不频繁被重启<br>- logback AsyncAppender 队列不饱和 |

### adb 长稳采集脚本：

```bash
#!/bin/bash
PKG=info.androidaps.aaps
LOG=/tmp/stability_$(date +%Y%m%d_%H%M).log
echo "# timestamp,PSS_kB,Activities,Services,process_exists" >> $LOG
for i in $(seq 1 72); do  # 6h x 60min / 5min = 72 samples
  ts=$(date +%Y-%m-%d_%H:%M:%S)
  pss=$(adb shell dumpsys meminfo $PKG 2>/dev/null | grep "TOTAL PSS" | awk '{print $3}')
  act=$(adb shell dumpsys activity activities 2>/dev/null | grep -c "mResumedActivity")
  svc=$(adb shell dumpsys activity services $PKG 2>/dev/null | grep -c "ServiceRecord")
  alive=$(adb shell pidof $PKG | wc -c)
  echo "$ts,$pss,$act,$svc,$alive" >> $LOG
  sleep 300
done
echo "=== crash log ===" >> $LOG
adb logcat -d AndroidRuntime:E -t 1000 >> $LOG
```

## 附录：已知风险点

| # | 风险 | 来源 | 影响 | 缓解 |
|---|------|------|------|------|
| 1 | sandbox 下无法跑 Robolectric 测试 | TRAE sandbox 阻止 `~/.robolectric-download-lock` | 23 个 initializationError | 真机验证即可；核心逻辑单测不依赖 Robolectric |
| 2 | PreferenceKeySnapshotTest 漂移 | FixedOffsetPlugin 引入新 key `calibration_user_offset_mgdl` | 快照测试 FAIL | 快照自动重写（已生成 diff，确认 fork 行为） |
| 3 | ContributedPluginsTest 漂移 | FixedOffsetPlugin 引入 order key 720 | 快照测试 FAIL | 同上 |
| 4 | minSdk 27 无法用 play-services-basement | GMS 最低 API 依赖 | M53P 无 GMS 恰好规避 | 已加 Phase 0 CGM 白名单解除（commit 1efc0d5） |
| 5 | Android 8.1 通知渠道不支持 IMPORTANCE_MIN | Android O 引入的 channel API 行为差异 | 可能导致通知无声 | 实测验证 TC-1.4 |
| 6 | Android 8.1 `JobScheduler.setImportantWhileForeground` | API 27 才加入的方法 | 低风险：代码已标记门控 | Phase 1 已清点 |
